\# OverTheWire Bandit — Learning Notes



\## Level 0

\- \*\*Concept:\*\* SSH into a remote server

\- \*\*Command:\*\* ssh bandit0@bandit.labs.overthewire.org -p 2220

\- \*\*SSH syntax:\*\* ssh username@host -p port

\- \*\*Mistake:\*\* Forgot to specify username, it defaulted to my Windows user (devav) and got permission denied

\- \*\*Lesson:\*\* Always specify the username before @ in SSH
